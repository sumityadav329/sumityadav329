## 🛠️ Projects at Nordic Design House Pvt. Ltd.

> What I built, shipped and maintained as a **Full-Stack & AI Engineer** in a fast-moving startup.

<details open>
<summary><b>👁️ Nordic Vision — AI-powered industrial inspection platform</b></summary>
<br>

- **Nordic ONE Vision Module (NOVM)** — computer-vision plugin of the factory OS that inspects **100% of manufactured parts** and feeds results into MES quality records.
- Built **YOLOX + PatchCore training/ONNX-export pipelines** and a headless anomaly-learning CLI with flat-dataset support.
- Fixed C++ rasterizer robustness, production capture paths, and **parallelized camera-open** for multi-station inspection.
- Implemented **color-presence, ground-flat-angle, pose and guided-circle** inspection tools with mm/px calibration in the part recipe.
- Added per-image capture logs, fast-lane PLC polling, and GPU/CUDA runtime pinning for reliable factory inference.

</details>

<details>
<summary><b>🤖 Nordic Vision Model Trainer — "Industrial AI Inspector"</b></summary>
<br>

- Built a **PySide6 desktop app** for PatchCore anomaly detection on top of `anomalib` — train on GPU/CPU, validate and export ONNX, all in one process.
- Replaced the PatchCore-only training page with **model-selected training** and listed YOLOX alongside PatchCore.
- Migrated install from pip/conda to **uv**; scaffolded per-project training/general logs; fixed the inference layout so both image panels stay visible.

</details>

<details>
<summary><b>🏗️ Nordic Vision Monolithic — machine-vision core</b></summary>
<br>

- Python + C/C++ **monolithic vision platform** — one deployable Vision Platform, many machine deployments (cameras, PLCs, recipes as configuration).
- Threaded **station_id** through RUN-model prewarm, prevented tile growth and pinned the CUDA runtime for stable GPU inference.
- Exposed **line-scan encoder/trigger** settings in Camera Manager; added UI capture-log wiring and per-image capture logs.

</details>

<details>
<summary><b>📄 Nordic Vision Patent Mono (Patent Pending)</b></summary>
<br>

- Patent-pending vision platform — metrology, color-presence, ground-flat-angle, pose and guided-circle inspection tools.
- Per-image capture logs, camera-aware crop diagnostics, fast-lane PLC poll thread, and per-machine GPU/CUDA pinning.

</details>

<details>
<summary><b>🧾 Nordic OS — enterprise operating platform</b></summary>
<br>

- Built and styled **RBAC (admin/CEO roles), procurement, projects, finance cockpit and value-stream engineering** modules.
- Fixed **SalesInvoice/LeadStatus enums** + Prisma regeneration; stabilized **ECS/ECR CI-CD** (image cleanup, stability checks).
- Drove a clean Scandinavian/minimal enterprise UI — matte-black folder icons, refined micro-interactions, standardized typography.

</details>

<details>
<summary><b>📦 Nordic ERP — Vue 3 + FastAPI enterprise resource planning</b></summary>
<br>

- Built **production efficiency, loss-breakdown, quality fallout and analytics-reporting** modules.
- Improved **Production Log Book** layout/functionality, costing/master price flow, and Tailwind styling each sprint.
- Added legacy `machine_type` compatibility and machine filters across the app.

</details>

<details>
<summary><b>🏭 Nordic MES — manufacturing execution system</b></summary>
<br>

- Extended **quality, production log book, packing and store-reference** modules.
- Updated user/department associations, role-based permissions and Docker-based **VM deployment**.
- Ubuntu packaging fixes and IoT gateway build improvements.

</details>

<details>
<summary><b>✅ Nordic E-QMS — electronic quality management system</b></summary>
<br>

- Quality management with real-time status and **Azure cloud integration** (Docker/Node/Azure CLI deployment).

</details>
